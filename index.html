01 / O que é?

O que é

programação web

Programação Web é o desenvolvimento de sites e aplicações que funcionam na internet. Ela combina diferentes tecnologias para criar páginas interativas visuais e funcionais, que podem ser acessadas de qualquer lugar, em qualquer dispositivo.




02 / tecnologias

As principais

tecnologias

Cada tecnologia tem um papel importante na construção de um site. Juntas, elas formam a base da programação web.

HTML Estrutura

É o esqueleto da página. Define o conteúdo e a organização do site.

<div>
    <p>Hello, world!</p>
</div>
CSS Estilo

Deixa o site bonito e organizado. Cuida das cores, fontes, layout e design.

.botao {
    background: #6c63ff;
    color: #fff;
}
JavaScript Interação

Adiciona dinamismo e faz o site funcionar de verdade. É o que permite ações, animações e respostas do usuário.

document.querySelector('.botao')
.addEventListener('click', () => {
    alert('Hello, world!');
});
SQL Banco de Dados

Linguagem de consulta usada para armazenar, organizar e manipular dados em bancos de dados relacionais.

SELECT nome, email
FROM usuarios
WHERE ativo = 1
ORDER BY nome;
PHP Backend

Linguagem de programação amplamente usada no desenvolvimento web, especialmente para aplicações dinâmicas e sistemas.

<?php
    $nome = 'Larissa';
    echo "olá, $nome!";
?>
Node.js Backend

Ambiente de execução JavaScript que permite criar aplicações do lado do servidor, usando o mesmo JavaScript do front-end.

const express = require('express');
const app = express();
app.get('/', (req, res) => {
    res.send('servidor rodando!'); });
app.listen(3000, () => console.log('Porta 3000'));



03 / carreiras

Onde posso trabalhar com programação web?

Com o conhecimento em programação web, você pode atuar em diversas áreas do mercado de tecnologia. Essa área está em constante crescimento e oferece muitas oportunidades, tanto no Brasil quanto no exterior.

Front-end Developer

Cria a parte visual e interativa dos sites, usando tecnologias como HTML, CSS e JavaScript.

Back-end developer

Cuida da lógica de programação e do funcionamento por trás do site, com linguagens como PHP, Node.js, Python, entre outras.

Full Stack Developer

Trabalha tanto no front-end quando no back-end, unindo o visual e a lógica do sistema.

Desenvolvedor Mobile

Cria aplicativos para dispositivos móveis, como smartphones e tablets.

Administrador de banco de dados

Gerencia e organiza informações, garantindo a segurança e o bom funcionamento dos dados.

ui/ux designer

Trabalha na experiência e no design do usuário, deixando os sites e aplicativos mais intuitivos e bonitos.
